# Customer Churn Analysis Dashboard

## 1. Project Overview
This project focuses on analysing customer churn data to understand customer behaviour, identify churn patterns, and explore factors that may affect customer retention.

The goal is to turn raw customer data into meaningful insights through data analysis and an interactive Power BI dashboard.

## 2. Project Objectives
- Understand customer churn patterns.
- Analyse customer characteristics and behaviour.
- Identify possible factors associated with customer churn.
- Explore differences between retained and churned customers.
- Present findings through clear dashboard visualisations.

## 3. Tools and Technologies
- **Power BI:** Dashboard development and data visualisation.
- **Power Query:** Data cleaning and transformation.
- **CSV:** Source dataset.

## 4. Project Workflow

### Step 1: Data Collection
Started with a customer churn dataset in CSV format to explore customer information and churn status.

### Step 2: Data Cleaning and Preparation
Prepared the dataset for analysis by checking the data, reviewing column types, and making it suitable for reporting.

### Step 3: Data Analysis
Explored the dataset to understand customer churn, compare customer groups, and identify patterns that could support retention decisions.

### Step 4: Dashboard Development
Created a Power BI dashboard to present the analysis using charts, key metrics, and visual comparisons.

### Step 5: Insights and Presentation
Organised the findings into dashboard pages to make the results easier to understand and explore.

## 5. Dashboard Highlights
The dashboard presents:
- Customer churn analysis
- Customer retention patterns
- Comparison of churned and retained customers
- Customer-related trends and distributions
- Visual summaries of important metrics

## 6. Project Files
- **Dataset:** Original customer churn CSV dataset.
- **Dashboard PDF:** Exported dashboard pages.
- **Screenshots:** Dashboard images for a quick preview.
